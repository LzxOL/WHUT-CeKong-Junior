## 📚 项目简介

本项目收集整理了武汉理工大学测控技术与仪器专业大三学年的专业课程资料，包括课程笔记、实验报告、课程设计、参考资料等。旨在为同专业学生提供学习参考，促进知识共享与交流。

## 2026.11.14更新
仪器仪表电路大作业中有部分错误：
1. 这个作业书3.3节的信号调制解调电路中，全波精密整流电路应修改为相敏检波电路以辨别相位方向。
2. 三位半数显表头 Protues 原理图存在问题，应更换为**三位半数显表头**而不是**LCD**，需自行更正。
